# 집길 지도 중심 첫 화면 디자인

작성일: 2026-08-08
상태: 사용자 승인 완료
상위 설계: `2026-08-08-housing-navigation-platform-design.md`

## 1. 목표

첫 접속 화면에서 사용자가 다음 두 경로를 즉시 이해하고 선택할 수 있게 한다.

1. 내 조건에 맞는 임대주택과 주거비 지원 찾기
2. 지도에서 매매·전세·월세 실거래 찾기

지도는 장식이 아니라 두 경로가 같은 지역 데이터를 공유한다는 사실을 보여주는 기본 화면이다. 두 진입 버튼의 크기와 위치는 동일하게 유지한다.

## 2. 승인된 시각 방향

- 밝고 신뢰감 있는 공공 데이터 서비스 분위기
- 실제 지도 위에 검색, 가격 정보, 진행 중 임대 공고를 함께 표시
- 짙은 청록색과 흰색을 주색으로 사용
- 제목은 부드러운 명조 계열, 본문과 조작 요소는 읽기 쉬운 고딕 계열 사용
- 과도한 카드 분할, 어두운 배경, 장식용 대시보드 형태는 사용하지 않음
- 작은 시안 여러 개가 아니라 한 화면을 크게 보여주는 구성

## 3. 데스크톱 구성

### 3.1 헤더

- 왼쪽: `집길` 로고
- 가운데: `주거 찾기`, `실거래 지도`, `이용 안내`
- 오른쪽: 공식 데이터 연결 상태와 마지막 확인 시각

### 3.2 지도

- 서울 지역을 중심으로 한 실제 지도 표현
- 상단 중앙에 지역·단지·주소 통합 검색
- 오른쪽에 확대, 축소, 현재 위치 도구
- 지도 위에 다음 정보를 구분해 표시
  - 실거래 대표 시세
  - 진행 중 임대 공고 수
- 지도 출처를 화면 하단에 표시

### 3.3 핵심 문구

제목은 `조건과 시세를 함께 보고, 살 곳을 정하세요.`를 사용한다.

설명은 임대주택과 실제 매매·전월세 가격을 같은 지도에서 이어서 확인할 수 있다는 점만 짧게 전달한다.

### 3.4 두 개의 진입 버튼

지도 하단에 같은 크기의 버튼 두 개를 나란히 배치한다.

#### 내게 맞는 주거 찾기

- 짙은 청록색 배경
- 임대주택, 주거비 지원, 예상 월 부담을 안내
- 클릭하면 지도를 유지한 채 질문 팝업을 연다

#### 지도에서 실거래 찾기

- 흰색 배경
- 지역 시세와 단지별 매매·전세·월세 거래를 안내
- 클릭하면 추가 질문 없이 실거래 지도 상태로 이동한다

색상은 다르지만 크기, 여백, 제목 크기, 화살표 위치를 동일하게 유지한다. 기능 우선순위 차이로 보이지 않아야 한다.

## 4. 임대주택 질문 팝업

- 데스크톱에서는 지도 오른쪽에 작은 팝업으로 표시
- 지도, 검색, 가격 정보는 팝업 뒤에서 계속 보임
- 한 화면에 한 질문만 표시
- 현재 단계와 진행률 표시
- 첫 질문은 희망 지역
- `현재 지도 주변`, 광역 지역 선택, 직접 검색을 제공
- 닫기 버튼 제공

팝업이 열릴 때 지도나 첫 화면 내용이 자동으로 이동하거나 잘리면 안 된다.

## 5. 모바일 구성

- 기준 폭은 390px
- 지도, 검색, 가격 정보, 두 진입 버튼을 한 화면 흐름으로 유지
- 헤더는 로고와 데이터 상태만 남겨 단순화
- 두 진입 버튼은 지도 하단에 세로로 배치
- 임대주택 질문은 하단 시트로 표시
- 하단 시트가 열려도 지도 상단과 선택 지역을 볼 수 있어야 함
- 가로 스크롤과 화면 밖 잘림을 허용하지 않음

## 6. 상호작용

### 임대주택 경로

1. 사용자가 `내게 맞는 주거 찾기`를 선택한다.
2. 지도 위치를 유지한다.
3. 데스크톱은 우측 팝업, 모바일은 하단 시트를 연다.
4. 질문에 따라 지도 선택과 검색 상태를 함께 갱신한다.

### 실거래 경로

1. 사용자가 `지도에서 실거래 찾기`를 선택한다.
2. 질문 화면을 열지 않는다.
3. 현재 지도 상태를 실거래 탐색 모드로 전환한다.
4. 축소 상태에서는 지역 시세, 확대 상태에서는 단지·건물 거래를 표시한다.

## 7. 반응형과 접근성

- 데스크톱은 1440px 기준으로 설계하되 1280px에서도 가로 잘림이 없어야 함
- 모바일은 390px 기준으로 전체 핵심 기능이 보여야 함
- 버튼은 키보드로 접근 가능해야 함
- 팝업 열기, 닫기, 다음 질문 이동 시 포커스를 명확히 관리
- 상태와 기능을 색상만으로 구분하지 않고 문구를 함께 표시
- 지도 출처와 데이터 확인 시각을 읽을 수 있는 크기로 유지

## 8. 데이터와 지도 공급원

승인 목업은 지도 표현 확인을 위해 OpenStreetMap 타일을 사용했다. 실제 구현에서는 프로젝트가 사용하는 지도 공급원과 이용 조건을 확인한 뒤 같은 배치로 교체한다.

지도 공급원이 달라져도 다음 화면 계약은 유지한다.

- 지역·단지·주소 검색
- 지역 시세 표시
- 진행 중 임대 공고 표시
- 축소 지역 집계와 확대 단지·건물 전환
- 지도 출처 표시

## 9. 이번 단계의 비범위

- 실제 지도 SDK 연결
- 임대 공고 API 연결
- 실거래 API와 지도 핀 연결
- 질문 판정 로직
- 제품 화면 코드 변경
- 배포

이 항목들은 별도 구현 계획과 사용자 승인 후 진행한다.

## 10. 승인 기준

- 데스크톱에서 지도와 두 진입 버튼이 한 화면에 잘리지 않고 표시됨
- 모바일 검토 화면에서 전체 구조를 한 번에 비교할 수 있음
- 두 진입 버튼의 크기와 정보 비중이 동일함
- 임대주택 버튼을 누르면 지도 위 질문 팝업이 열림
- 팝업을 열어도 지도 내부가 자동 스크롤되지 않음
- 실거래 버튼을 누르면 질문 없이 지도 진입 상태가 표시됨
- 화면에 지도 출처와 데이터 확인 시각이 표시됨
